## 「ドリルはできるのに」と思ったことはある？

漢字や計算のドリルは、一人で進められる。
けれど、長い文章題や作文になると、手が止まる。

ノートを開いたのに、何から始めるか分からない。
考えているうちに時間が過ぎて、全部いやになることもあるかもしれません。

これは、課題で使う「道具」がちがうから起こることがあります。

どちらも学習です。かんたん・むずかしい、頭がよい・悪い、という分け方ではありません。
必要な道具がちがいます。

## 頭の中の仕事が増えている

考えることが多い課題では、頭の中で小さな作戦会議が開かれます。

<div class="ht-job-list" role="list" aria-label="考える課題で行う七つの仕事">
  <span role="listitem">問題を読む</span>
  <span role="listitem">聞かれていることを考える</span>
  <span role="listitem">方法を選ぶ</span>
  <span role="listitem">順番を決める</span>
  <span role="listitem">途中まで合っているか確かめる</span>
  <span role="listitem">ちがったら戻る</span>
  <span role="listitem">最後までまとめる</span>
</div>

これだけの仕事を、頭の中だけで同時に進めるのは大変です。
だから、紙に書いたり、人に話したりして、仕事を頭の外へ出します。
それが、このページで使う道具です。

## まずは課題を小さくする

大きな課題を前にしたら、次の五つの道しるべを使います。
全部の答えをすぐに出す必要はありません。今いる場所から、一つずつ進みます。

<ol class="ht-path" aria-label="課題を進める五つの手順">
  <li>
    <span class="ht-path-number" aria-hidden="true">1</span>
    <div><strong>ゴールを見る</strong><span>何ができたら終わり？</span></div>
  </li>
  <li>
    <span class="ht-path-number" aria-hidden="true">2</span>
    <div><strong>分かっていることを集める</strong><span>今、分かっていることは何？</span></div>
  </li>
  <li>
    <span class="ht-path-number" aria-hidden="true">3</span>
    <div><strong>最初の一歩を決める</strong><span>まず一つだけやるなら何？</span></div>
  </li>
  <li>
    <span class="ht-path-number" aria-hidden="true">4</span>
    <div><strong>少し試す</strong><span>どこまでなら試せそう？</span></div>
  </li>
  <li>
    <span class="ht-path-number" aria-hidden="true">5</span>
    <div><strong>進み方を確かめる</strong><span>さっきより何が分かった？</span></div>
  </li>
</ol>

分からない場所が見つかったら、作戦会議は前へ進んでいます。
「何も分からない」から「ここで止まった」に変わったからです。

## 「10分だけ作戦」

10分で、課題を全部終わらせようとしなくてかまいません。
次の中から一つ選び、課題を一つ前へ動かします。

  <label><input type="checkbox" /> 図を一つかく</label>
  <label><input type="checkbox" /> 作文に使う出来事を三つ書く</label>
  <label><input type="checkbox" /> 調べたい言葉を一つ決める</label>

10分で終わらなくても、失敗ではありません。
次にすることが分かったなら、前進です。

## 止まったときの三つの作戦

<div class="ht-strategy-grid">
  <section class="ht-strategy-card" aria-labelledby="ht-strategy-a">
    <p class="ht-strategy-label">作戦A</p>
    <h3 id="ht-strategy-a">もっと小さくする</h3>
    <p>「作文を書く」が大きすぎるなら、ここまで小さくします。</p>
    <ol>
      <li>書く出来事を決める</li>
      <li>一番伝えたいことを決める</li>
      <li>最初の一文を書く</li>
    </ol>
  </section>
  <section class="ht-strategy-card" aria-labelledby="ht-strategy-b">
    <p class="ht-strategy-label">作戦B</p>
    <h3 id="ht-strategy-b">形を変える</h3>
    <p>同じことを、別の形で考えます。</p>
    <ul>
      <li>文章を図にする</li>
      <li>声に出して説明する</li>
      <li>箇条書きにする</li>
      <li>実物を動かす</li>
      <li>紙に並べる</li>
      <li>だれかに話す</li>
    </ul>
  </section>
  <section class="ht-strategy-card" aria-labelledby="ht-strategy-c">
    <p class="ht-strategy-label">作戦C</p>
    <h3 id="ht-strategy-c">助けを借りる</h3>
    <p>答えではなく、進むための助けをたのみます。</p>
    <ul class="ht-speech-list">
      <li>「答えではなく、最初にすることを教えてください」</li>
      <li>「ここまで考えたけれど、この先で止まりました」</li>
      <li>「問題の意味をいっしょに確かめてください」</li>
      <li>「この二つなら、どちらから試すとよいですか」</li>
      <li>「一問だけいっしょにやってください」</li>
    </ul>
  </section>
</div>

助けを借りることと、答えをそのまま聞くことは同じではありません。
自分で進める場所まで、道をいっしょに探してもらえます。

## やることが多い日は、先に一つ選ぼう

やることがいくつもあるときは、すぐに順番を決めなくてかまいません。
まず全部を書き出して、「今日やる」「あとでやる」「いっしょにやる・相談する」に分けます。

次の順番で考えると、今やる一つを選びやすくなります。

1. 今日までのものはある？
2. 今なら助けてもらえるものはある？
3. どちらもなければ、いちばん始めやすいものはどれ？

「あとでやる」に分けることも、大切な作戦です。
今は一つだけ選び、短い時間で始めます。

宿題だけでなく、休けいや遊び、明日の準備もふくめて一日を整えたいときは、先に[子どもの時間のつかい方](/manabi-commons/school-guide/kodomo-no-jikan-tsukaikata/)を使います。
そこで選んだ一つが大きくて始められないときに、この作戦ノートで最初の一歩まで小さくします。

## 「一人でできる」には途中の段階がある

一人でできるか、できないか。二つだけで考える必要はありません。

## 最後に

むずかしい課題を、最初から一人で全部できなくてもかまいません。
まず、小さく分けます。少し試します。止まった場所を見つけます。

分からない場所が分かったら、それも前進です。
助けを使いながら、自分でできる部分を少しずつ増やせます。

あなたに合う進み方は、試しながら見つけていくものです。
次の課題では、どの作戦から使いますか。

## 保護者・先生の方へ

<h3 id="ht-adult-title">進め方をいっしょに言葉にする</h3>

- 答えを急いで示すより、「最初に何をするか」をいっしょに確認します。
- 「どうして分からないの」ではなく、「どこまで分かった」と聞きます。
- 一緒に行う範囲を、様子を見ながら少しずつ減らします。
- 完成度に加えて、着手、再開、質問、振り返りも見ます。
- 全部を一人で行うことだけを、自立とは考えません。
- 工作、料理、準備、片づけなどでも、同じ進め方を練習できます。
