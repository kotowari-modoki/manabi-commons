## ミッション6　イルカといっしょに泳ごう

### 水族館のなぞをとこう

笛の合図のメモが、水にぬれてしまいました。
ヒントを読んで、笛の回数とわざを線でむすびましょう。

- ヒント1：笛が一回鳴ったら、ジャンプの合図。
- ヒント2：二回は、あいさつの合図ではない。

| 笛の回数 | 　 | わざ |
| --- | --- | --- |
| 一回 | ・　　・ | しっぽふり |
| 二回 | ・　　・ | ジャンプ |
| 三回 | ・　　・ | あいさつ |

### 一文を書こう

「練・習・曲・笛・第」の中から1字えらんで、水族館の文を作りましょう。
（れい：笛の合図で、練習が始まる。）
