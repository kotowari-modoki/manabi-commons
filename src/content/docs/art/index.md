# 図工・アートで楽しく表現しよう

図工は、学校だけで終わりではありません。

- 見て、感じて、表現すること
- 手を動かして何かを作ること
- 失敗しながら工夫すること

は、家でも続けられます。

このセクションでは、小学生が家でできるアート活動と、保護者のみなさんが安心して準備できるガイドをまとめています。

小学校高学年向けには、図工の制作過程そのものを練習できる印刷用シートも用意しています。
よく見て、いくつかの方法を試し、自分で選んで作品にしていく進め方を、シートに書きこみながら身につけます。

### 高学年向け：試して選ぶ活動シート

- [アイデアを3つ出す](idea-mitsu/) — 最初の案をそのまま完成させず、3つを比べてから選びます
- [観察して描く](kansatsu-shite-kaku/) — 同じ題材を、全体・部分・輪郭・光と影など違う見方で描き比べます
- [色をつくる実験](iro-wo-tsukuru/) — 同系色・明るさ・補色などを実際に塗って、自分の感じに近い色を探します
- [構図を試す](kouzu-wo-tamesu/) — 同じ題材を、置き方・切り取り方を変えて小さく試し描きします
- [材料実験ノート](zairyou-jikken-note/) — 鉛筆・絵の具・段ボールなど、いろいろな材料と方法を試して記録します
- [作品振り返りシート](sakuhin-furikaeri/) — 完成した作品の制作過程を、採点なしで自分の言葉で振り返ります
