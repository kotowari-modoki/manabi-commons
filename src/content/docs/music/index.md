# 音楽

音楽のページでは、楽譜を読む力を、少しずつ身につけていきます。

- 五線譜の仕組みと、音の高さの見分け方
- 音符と休符が表す長さ
- 拍子と小節のつながり
- 楽譜を練習するときの進め方

を大切にします。

楽器がなくても、手拍子や声を使って始められる内容になっています。
音を聴ける環境なら、ページの中のボタンでメロディーを聴くこともできます。

## このセクションのページ

- [五線譜と音の高さ](gosenfu-to-oto-no-takasa/) — 五線と間、ト音記号、真ん中のドから高いドまでの読み方
- [音符と休符の長さ](onpu-to-kyuufu/) — 四分音符・八分音符・二分音符・全音符と、四分休符の長さ
- [拍子と小節](hyoushi-to-shousetsu/) — 拍と小節、4分の4拍子と3拍子、弱起
- [楽譜の練習方法](gakufu-no-renshuu/) — 難しい部分を見つけて区切る練習の進め方と、印刷できる練習作戦シート

## 読むときのやくそく

- 分からない記号が出てきたら、あわてずに一つずつ確かめます
- 音を聴けないときは、手拍子や指の動きで確かめます
- うまく弾けない部分は、区切って少しずつ練習します

楽譜を読む力は、少しずつしか身につきません。
できたところを見つけながら、ゆっくり進めましょう。
