# 出典とレビューのポリシー

まなびコモンズでは、教材の正確性、読みやすさ、安全性を守るために、出典とレビューの記録を重視します。
AI支援を使った場合も、最終的には人間が教材としての妥当性を確認します。

## 参考情報源の優先順位

1. 学習指導要領、文部科学省などの公式資料
2. 公的機関、大学、博物館、研究機関などの教育資料
3. 信頼できる辞典、参考書、専門書
4. 教師・保護者・学習者からの具体的なフィードバック
5. AI支援の提案

AI支援の提案は、参考情報源そのものではなく、編集の補助として扱います。

## 学習指導要領との対応

教材を追加・大幅更新するときは、可能な範囲で次を説明できるようにします。

- 学年
- 教科
- 単元
- 学習指導要領との対応
- 前提となる学習内容

必要に応じて `learning_context` に残します。

```yaml
learning_context:
  grade: 小学2年
  subject: 算数
  unit: 九九
  curriculum_ref: "学習指導要領 算数 第2学年 A 数と計算"
  prerequisite: たし算
```

## レビュー観点

- 事実関係が正しいか
- 対象学年に合っているか
- 例題と解説が一致しているか
- 用語が学年相応か
- 子どもが危険な行動をまねしないか
- 偏りや決めつけがないか
- 保護者・教師が見ても説明しやすいか

## 過去教材との違い

既存教材と説明が変わる場合は、次を残します。

- 何を変えたか
- なぜ変えたか
- どの参考情報源を確認したか
- 人間レビューが必要か

```yaml
content_status:
  claim_status: needs_revision
  related_pages:
    - /math/sho2-kuku-oboekata/
  update_note: "説明方法を変えたため、例題と対象学年の確認が必要。"
```

## レビュー完了の扱い

`review.human_review: completed` は、少なくとも人間が本文、例題、出典、対象学年、安全性を確認した状態を表します。
レビューが部分的な場合は `required` のままにし、PRコメントで未確認点を明記します。
